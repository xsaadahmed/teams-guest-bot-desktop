# Portable bundle (not in this repo)

This repository ships the **Electron desktop app** via GitHub Releases.

For locked-down corporate laptops that need a **git-clone portable bundle** (no installer,
no npm), use the companion repository:

**[teams-guest-bot-windows](https://github.com/xsaadahmed/teams-guest-bot-windows)**

```cmd
git clone https://github.com/xsaadahmed/teams-guest-bot-windows
cd teams-guest-bot-windows
Unpack-Bundle.cmd
Start-Bot.cmd
```
